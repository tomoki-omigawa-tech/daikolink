# 工数見積もり・スケジュール

## 前提
- 開発期間：Week 22〜24（3週間・1人）
- 稼働：1週間あたり約35時間（1日5時間 × 7日）→ 合計約105時間
- 1ポイント＝1時間の目安で見積もり、バッファは開発工数の25%
